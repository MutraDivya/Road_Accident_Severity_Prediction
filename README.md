# 🚗 Road Accident Severity Prediction

## 📌 Overview

Road Accident Severity Prediction is a machine learning project that predicts the severity of road accidents. It includes a Streamlit web app, a trained model, and a Jupyter notebook for model development.

---

## ✨ Features

- Predict road accident severity using the trained model
- Interactive web app built with Streamlit
- Saved model for making predictions
- Jupyter notebook for data exploration and model development

---

## 🛠️ Technologies Used

- Python 3
- Streamlit
- Jupyter Notebook
- Joblib
- Machine Learning
